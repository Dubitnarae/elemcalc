# 원소 함량 계산기 2.17

합금 조성 계산과 칭량을 위한 프로그램입니다. 만든 사람: KIM YEONGDO

- at% ⇄ wt% 변환, 비중 추정, 평균 원자량
- 원료(순수 원소·모합금)별 칭량값 계산: 순도, 회수율, 단가, 최저 원가 조합
- 실제 칭량값으로 실제 조성 역계산
- 조성식 입력, 조성 시리즈 일괄 계산, 용탕 성분 보정

## 설치와 실행

**설치해서 쓰기 (권장)**
1. `배포\elemcalc_v2.17_setup.zip`을 원하는 곳에 풉니다. 다른 PC에 줄 때도 이 zip 하나면 됩니다.
2. 압축을 푼 폴더에서 `설치.cmd`를 더블클릭합니다. 관리자 권한은 필요 없습니다.
3. 바탕화면이나 시작 메뉴의 **원소 함량 계산기**로 실행합니다. `.alloy` 파일을 더블클릭해도 열립니다.
4. 제거: Windows 설정 → 앱 → 설치된 앱 → 원소 함량 계산기 → 제거
5. **자동 업데이트**: 새 버전이 나오면 켤 때(하루 한 번) 알림이 뜹니다. **지금 업데이트**를 누르면 새 버전을
   받아 설치하고 계산기를 다시 켭니다(저장하지 않은 내용이 있으면 먼저 묻습니다. 설정·내 모합금은 유지).
   직접 확인은 **도움말 → 업데이트 확인**, 알림을 끄려면 **도움말 → 시작할 때 새 버전 확인**을 해제합니다.
   설치 없이 쓰는 휴대용 exe는 자동 업데이트가 되지 않고 **내려받기 페이지**로 안내합니다.
   업데이트에 실패하면 이전 버전이 다시 열립니다.
   - 알림 창에는 GitHub 릴리스 **설명**에 적어 둔 이번 버전의 변경 사항이 그대로 보입니다.
   - 설치 직전에 설정(내 모합금, 원소별 순도·회수율·단가, 최근 파일)을
     `%LOCALAPPDATA%\Du_App\ElementCalc\settings_backup`에 자동으로 복사해 둡니다(최근 5개).
     문제가 생기면 **도움말 → 설정 백업에서 복원**으로 되돌립니다.
6. **문제가 생기면**: **도움말 → 문제 보고용 파일 만들기**로 zip 하나를 만들어 보내 주세요. 프로그램 버전, 환경,
   오류 내용, 업데이트 기록만 들어 있고 조성·칭량값 같은 작업 내용은 들어 있지 않습니다.
   예상하지 못한 오류가 나면 알림 창에서 바로 만들 수도 있습니다. 기록은
   `%LOCALAPPDATA%\Du_App\ElementCalc\logs`에 쌓입니다(최대 약 800KB, 오래된 것부터 지워짐).

**설치 없이 쓰기:** `원소함량계산기_v2.exe`를 바로 실행합니다. 켜질 때 몇 초 더 걸립니다.

> 다른 PC에서 처음 실행하면 Windows가 "PC 보호" 화면을 띄울 수 있습니다.
> **추가 정보 → 실행**을 누르세요. 코드 서명 인증서가 없는 프로그램이라 나오는 안내입니다.

## 사용법

### 1. 목표 조성
- 주기율표에서 원소를 누르거나 검색창에 `Fe`, `니켈`처럼 입력합니다.
- **조성식 칸**에 한 번에 입력할 수도 있습니다.
  - `Fe73.5Si13.5B9Nb3Cu1`, `Ti50Ni50`, `TiNi` → at% (비율은 100으로 환산)
  - `Fe-18Cr-8Ni` → wt%, 숫자가 없는 원소(Fe)는 잔부
- **입력 기준**(at% / wt%)을 고르고 파란 칸에 함량을 넣으면 입력하는 대로 계산됩니다.
- **잔부**에 체크한 원소는 100%에서 나머지를 뺀 값이 됩니다.
- **회수율(%)**: 용해 중 산화·증발로 줄어드는 원소(Mn, Mg, B, C 등)는 회수율을 낮추면 그만큼 더 넣도록 계산합니다.

### 2. 칭량
- 오른쪽 **총 질량**(완성될 합금의 g)을 넣으면 **칭량 원료** 표에 원료별 칭량값이 나옵니다.
- **모합금**: `＋ 모합금 추가`에서 대표 예시(`Fe-B(16.5wt%) [이엠엘]`, `Al-Cu(20wt%) [이엠엘]` 등 이엠엘 보유 모합금)를 고르거나 직접 만듭니다.
  - 추가하면 주 첨가 원소(Fe-B의 B)의 순수 원료가 자동으로 꺼집니다.
  - 이름은 `Fe-C(14wt%)`처럼 조성에 맞춰 붙고, **내 모합금**에 저장됩니다.
  - **내 모합금**에 있는 것은 누르면 창 없이 바로 칭량 원료에 들어갑니다. 대표 예시는 조성을 확인하는 창이 먼저 뜹니다.
    같은 이름으로 내 모합금에 저장하면 그 대표 예시는 목록에서 사라집니다(내 모합금에서 지우면 다시 나타남).
  - 모합금 행을 더블클릭하면 조성(밀시트 분석값)을 고칠 수 있습니다.
- **순도(%)**: 순수 원료의 순도를 넣으면 그만큼 더 넣고, 들어가는 불순물 양을 알려 줍니다.
- **단가(/kg)**: 원료비가 계산됩니다. **최저 원가로 원료 고르기**를 켜면, 같은 원소를 넣을 원료가
  여럿일 때 가장 싼 조합을 고릅니다(켜진 원료 모두에 단가가 있어야 합니다).
- **실제 칭량(g)**: 저울에 실제로 단 값을 넣으면 조성 표의 **실제 wt%**에 실제로 만들어진 조성이 나옵니다.
  아직 넣지 않은 원료는 계획값으로 가정합니다. 목표와 다르면 주황색으로 표시됩니다.
- 순도·회수율·단가는 원소별 기본값으로 기억해서 다음에 그 원소를 넣을 때 자동으로 채웁니다.
- 원소 질량이나 원료 칭량값 칸에 숫자를 넣으면 거기에 맞춰 총 질량이 바뀝니다
  (가진 모합금 덩어리를 다 쓰고 싶을 때 등).

### 3. 도구
- **조성 시리즈** (Ctrl+T): `Fe(100-x)Bx`, `Co(75-x/2)Fe(x/2)B25`처럼 x가 든 식과
  x 값(`10:20:2` 또는 `10, 12, 15`)을 넣으면 여러 조성의 원료 칭량값을 한 번에 계산하고 엑셀로 냅니다.
  표에서 하나를 골라 메인 화면으로 불러올 수 있습니다.
- **용탕 성분 보정** (Ctrl+R): 지금 용탕 무게와 분석값을 넣으면 목표 조성까지 원료를 몇 g 더 넣을지 계산합니다.
  이미 너무 많은 원소는 다른 원료를 더 넣어 희석하는 방식으로 맞춥니다(가장 적게 넣는 조합).

- **휴대폰으로 보내기** (Ctrl+M): QR 코드를 휴대폰 카메라로 찍으면 칭량 웹앱이 열리고, 저울 값을 입력한 뒤
  **결과 보내기**로 카톡 등에 보냅니다. PC에서는 그 글을 복사해 **휴대폰 칭량 결과 넣기**(Ctrl+Shift+M)에
  붙여 넣으면 실제 칭량값이 들어갑니다. 웹앱 주소(`https://dubitnarae.github.io/elemcalc/`)는 프로그램에 들어 있어서 따로 입력하지 않습니다.
- **칭량지 인쇄** (Ctrl+P): 원료별 칭량값, 확인 칸, 허용 오차를 담은 종이 칭량지를 인쇄하거나 PDF로 저장합니다.
  QR 코드를 넣으면 휴대폰 칭량으로 이어집니다.

### 4. 파일
- 저장/열기: `.alloy` 파일 (원료 설정, 실제 칭량값까지 모두 저장). 이전 버전의 `.json` 파일도 열 수 있습니다.
- **자동 복구**: 바뀐 내용이 있으면 3초마다 `%LOCALAPPDATA%\Du_App\ElementCalc\recovery`에 자동 저장합니다.
  정전·강제 종료 등으로 저장하지 못하고 끝났다면, 다음에 켤 때 "복구할까요?"를 묻습니다.
  저장하거나 정상 종료하면 이 임시 파일은 지워집니다. 파일을 열고 시작한 경우에는 다음 실행 때 묻습니다.
- **저장 백업**: 저장할 때마다 `...\ElementCalc\backups`에 날짜·시간이 붙은 사본을 남기고(파일마다 최근 20개,
  내용이 같으면 건너뜀), **파일 → 백업에서 열기**로 불러옵니다. 백업을 열면 새 파일로 열려서 백업 원본은 바뀌지 않습니다.
- 엑셀 내보내기: **조성** 시트와 **칭량** 시트(원료별 칭량값, 실제 칭량값, 확인 칸)
- 되돌리기 Ctrl+Z, 다시 실행 Ctrl+Y

## 계산 방법

- wt%ᵢ = Mᵢ·at%ᵢ / Σ(M·at%) × 100, at%ᵢ = (wt%ᵢ/Mᵢ) / Σ(wt%/M) × 100
- 비중 = 1 / Σ(wᵢ/ρᵢ): 무게비 기준 혼합 법칙에 따른 **추정값**입니다. 실제 합금 밀도와는 상·조직에 따라
  차이가 날 수 있습니다. 밀도가 알려지지 않은 원소는 빼고 계산합니다.
- 원료 칭량: 원료 r의 원소 e 함량 a, 회수율 y, 목표 원소 질량 m에 대해 Σ a·y·x = m, x ≥ 0을 풉니다.
  보통은 음수 불가 최소제곱, 최저 원가일 때는 선형계획법(단체법)을 씁니다.
  맞출 수 없는 조합이면 실제로 나오는 조성과 차이를 경고로 보여 줍니다.
- 순도가 99.5%이면 나머지 0.5%는 '불순물'로 따로 계산합니다(목표 조성에는 넣지 않음).

## 데이터

- 원자량: IUPAC 표준 원자량(관용값). 안정 동위원소가 없는 원소는 가장 오래 사는 동위원소의 질량수.
- 밀도: 상온 문헌값(g/cm³), 기체는 0 °C, 1 atm.
- 모합금 대표 예시는 일반적인 시판 등급 조성입니다. 실제 원료의 분석값으로 고쳐 쓰세요.
